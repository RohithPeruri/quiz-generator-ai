Internship Mini Project – AI Quiz Generator
Project Overview
The AI Quiz Generator is a simple Python-based application that asks quiz questions, accepts user answers, checks correctness, calculates scores, and displays results automatically. It behaves like a basic AI assistant by interacting with users through the terminal.
Project Objective
Develop a Python quiz application that can:
1 Ask questions
2 Accept answers
3 Validate answers
4 Calculate score
5 Display final result
Project Description
The application works in the terminal/command prompt and allows users to answer quiz questions one by one. The system checks answers, updates scores, and displays the final result at the end.
Mandatory Features
1 Welcome Message
2 Minimum 5 Quiz Questions
3 User Answer Input
4 Answer Validation
5 Score Calculation
6 Loop for Multiple Questions
7 Final Result Display
8 Save Score in Text File

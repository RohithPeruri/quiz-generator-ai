# AI Quiz Generator

## Project Description
AI Quiz Generator is a Python-based mini project that asks quiz questions, checks answers, calculates scores, and displays final results.

## Features
- Welcome Message
- Multiple Quiz Questions
- User Input
- Answer Validation
- Score Calculation
- Final Result Display
- Save Score in Text File

## Technologies Used
- Python

## Project Files
- quiz.py → Main Python program
- questions.txt → Stores quiz questions and answers
- scores.txt → Stores user scores
- README.md → Project documentation

## How to Run

1. Install Python
2. Open terminal in project folder
3. Run command:

```bash
python quiz.py
